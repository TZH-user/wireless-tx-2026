## 1. 结论

**ADC 在 2.0VPP RF 输入下完全没有削顶。**

| 项目 | 结论 |
|---|---|
| 推荐 RF 安全上限 | >= 2.0VPP (当前 RF 信号源最大输出) |
| 2.0VPP 是否削顶 | 否，clip count = 0 全部 |
| 哪一路先接近限制 | 无 (I/Q 均远低于 ADC 满量程) |
| 是否随频点变化 | 否 (30/40/50 MHz 表现一致) |
| 调制是否更容易超限 | 否 (CW 和所有调制模式无差异) |
| 后续建议默认 RF VPP | 1.5VPP (当前基线，稳定且远在安全区内) |

## 2. 测试方法

在固件中新增 `adc_range` 日志，对每个 ADC 块（4096 samples）统计：
- I/Q min / max / VPP
- 近轨计数 (near rail: 距上下轨 <= 1%FS = 655 lsb)
- 削顶计数 (clip: raw <= 10 或 raw >= 65525)

日志每 1s 输出一次，覆盖 sigdet_final 锁定之后的全程数据。

## 6. 关键发现

### 6.1 ADC 有效动态范围极低

当前 ADC 实际使用的 I/Q 数据范围仅约 7800-8300 (约 500 lsb)，占 16-bit 满量程 (65535) 的 **~0.8%**。

这意味着：
- ADC 前端 (LTC5584 + LPF + 偏置网络) 的输出摆幅非常小。
- ADC 输入几乎没有被利用。
- 不存在来自 ADC 的削顶风险。

### 6.2 2.0VPP CW 误判与 ADC 削顶无关

扩展矩阵测试中发现 CW 在 2.0VPP 下被误判为 PSK。本轮测试证实：**ADC 完全没有削顶**，因此该误判不是 ADC 削顶导致的。

误判原因仍需从以下方向排查：
- LTC5584 在 2.0VPP 输入下的线性度/IQ 平衡退化
- RF 前端在大信号下的交调或谐波
- 软件算法中 CW 判据对大幅值下的 psk_jump_pm 和 freq_activity 敏感

### 6.3 I/Q DC 偏置

I 通道中心约 8100，Q 通道中心约 8000。这个 DC 偏置来自 LTC5584 的输出共模电平。当前偏置在 ADC 范围内是安全的，但距离常用 "ADC mid-code" (~32768) 很远，说明：
- 要么 LTC5584 输出共模电平本来就偏低
- 要么 ADC 参考电压配置与 LTC5584 输出不匹配
- 要么 LPF/偏置网络的直流工作点需要调整

当前不影响功能，但若将来需要更大动态范围，应考虑调整偏置使信号居中。

## 7. 建议

1. **后续测试默认使用 1.5VPP** — 已验证稳定，远在 ADC 安全区内。
2. **2.0VPP CW 误判问题** — 建议从 IQ 正交平衡和 LTC5584 线性度方向排查，而非 ADC 削顶。
3. **ADC 动态范围** — 若将来需要更好的 SNR，考虑调整 LTC5584 后的增益级或 ADC 参考电压。
4. **不建议继续提高 RF VPP** — 当前 ADC 远未饱和，但 RF 前端在其他方面 (LTC5584 线性区) 可能先于 ADC 出现问题。
5. **保留 adc_range 日志** — 建议作为长期调试辅助字段保留，对后续排查硬件问题有价值。
