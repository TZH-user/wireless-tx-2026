在当前 `Simple_wireless_IQ_demodulation` 工程中引入基带频谱显示功能。

初版目标不是修改调制识别算法，而是在屏幕和日志中显示锁定后 I/Q 基带频谱的摘要信息，用于后续观察 AM/FM/FSK/PSK 特征。

## 5. 推荐实现

### 5.1 模块接口

建议新增：

```c
void app_baseband_spectrum_init(uint32_t sample_rate_hz);
void app_baseband_spectrum_process_iq_block(const uint16_t *i_buf, const uint16_t *q_buf, uint32_t sample_cnt);
void app_baseband_spectrum_get_status(app_baseband_spectrum_status_t *out);
```

状态字段建议：

```c
typedef struct
{
  uint8_t valid;
  uint8_t reserved[3];
  uint32_t block_count;
  uint32_t sample_rate_hz;
  uint32_t peak_hz;
  uint32_t peak_mag;
  uint32_t noise_floor;
  uint32_t dc_mag;
} app_baseband_spectrum_status_t;
```

### 5.2 初版算法

优先低风险实现：

- 从每个 ADC block 取固定点数，例如 `256` 或 `512`。
- I/Q 先减均值，避免 DC 峰压制频谱。
- 初版可先做简化频域能量估计或小点数 FFT。
- 如果使用 CMSIS-DSP，确认工程已正确链接对应源文件/库。
- 如果 CMSIS-DSP 接入复杂，第一版允许先做 Goertzel/少数频点能量估计，保证构建通过。

### 5.3 调用位置

在 `AdcTask.c` 中，仅当：

```c
sig_status.stage == APP_SIGDET_STAGE_VPP_LOCKED &&
sig_status.locked != 0U &&
sig_status.carrier_present != 0U
```

才调用频谱处理。

与 `app_mod_detect_process_iq_block()` 并列，但不得阻塞 ADC 实时路径。

### 5.4 UI 显示

在 `app_lvgl_ui.c` 的频谱预留区域显示：

```text
Baseband Spectrum
Peak: xxx Hz
Mag: xxx
Noise: xxx
DC: xxx
LO: xx.xxx MHz
```

注意：

- `Peak Hz` 是基带频率，不是 RF 绝对频率。
- UI 上应保留 `Carrier` 和 `LO` 信息，避免误读。
