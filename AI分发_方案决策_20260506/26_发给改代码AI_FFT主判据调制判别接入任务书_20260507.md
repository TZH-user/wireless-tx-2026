## 5. 必须采纳的实现方式

### 5.1 主体结构

应保持：

```text
app_baseband_spectrum
  负责 FFT 和频谱特征

app_mod_detect
  负责最终 mode / stable_mode / confidence
```

不采纳：

- 在 `AdcTask.c` 里直接新增一套 `if-else` 主判别
- 新建一个与 `app_baseband_spectrum` 完全重复做 FFT 的大模块

### 5.2 FFT 输入

必须基于：

- 锁定后的 I/Q block
- 去均值
- Hann 窗
- 当前 `256` 点复数 FFT

可以继续沿用当前 `app_baseband_spectrum_run_once()` 的 FFT 内核，但要补充分类所需特征。

### 5.3 分类输入不能来自 UI 柱值

调制判别必须基于：

- 完整 FFT bin 能量
- 或由完整 FFT bin 派生的特征

不得基于：

- `bars[41]`
- 屏幕压缩后的 `0~1000` 柱值

## 6. 必须新增的 FFT 特征

至少新增以下可读取特征，可放入 `app_baseband_spectrum_status_t`，或新增专门特征结构体：

- `dc_ratio_pm`
- `near_ratio_pm`
- `mid_ratio_pm`
- `wide_ratio_pm`
- `edge_ratio_pm`
- `symmetry_pm`
- `peak_count`
- `dominant_pair_hz`
- `pair_ratio_pm`
- `harmonic_ratio_pm`

要求：

- 单位统一，建议频率用 `Hz`，比例用 `pm` 千分比
- 无效状态必须清零
- 失锁或频谱无效时不得保留旧值

## 7. 必须采纳的判别顺序

最终模式判别顺序必须按决策书执行：

1. `NO_CARRIER`
2. `CW`
3. `AM / ASK`
4. `FSK / PSK / FM`
5. 旧逻辑兜底

## 8. 初版阈值

按以下阈值接入 V1：

### 8.1 CW

```text
dc_ratio_pm >= 850
bw90_hz <= 3000
peak_count <= 2
```

### 8.2 AM

```text
env_variation_pm >= 180
symmetry_pm >= 850
pair_ratio_pm >= 350
harmonic_ratio_pm < 250
bw90_hz <= 25000
```

### 8.3 ASK

```text
env_variation_pm >= 180
symmetry_pm >= 650
(
  harmonic_ratio_pm >= 250
  or peak_count >= 4
  or bw90_hz > 25000
  or env_edge_pm >= 80
)
```

### 8.4 FSK

```text
env_variation_pm < 180
dc_ratio_pm <= 350
pair_ratio_pm >= 450
dominant_pair_hz >= 2000
psk_jump_pm < 80
```

### 8.5 PSK

```text
env_variation_pm < 180
psk_jump_pm >= 120
symmetry_pm >= 700
pair_ratio_pm < 450
bw90_hz >= 3000
```

### 8.6 FM

```text
env_variation_pm < 180
symmetry_pm >= 750
bw90_hz >= 5000
(pair_ratio_pm < 450 or dominant_pair_hz < 2000)
psk_jump_pm < 120
```
