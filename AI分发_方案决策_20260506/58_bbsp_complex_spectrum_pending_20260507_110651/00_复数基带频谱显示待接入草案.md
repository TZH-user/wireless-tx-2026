## 1. 目标规格

- 类型：复数基带频谱显示
- 频谱中心：`0Hz`
- 显示范围：`-100kHz ~ +100kHz`
- 柱数候选：`33` 或 `41`
- 步进候选：`5kHz` 或 `6.25kHz`

## 2. 本轮建议默认值

优先建议：

- 柱数：`41`
- 步进：`5kHz`
- 覆盖：`-100kHz, -95kHz, ... 0Hz ... +95kHz, +100kHz`

理由：

- `41` 柱刚好对称，中心柱就是 `0Hz`
- `5kHz` 步进和当前锁定/基带观测任务更直观
- UI 文本和后续柱状图都更容易解释
- 后续如果实测刷新负担偏大，再退到 `33` 柱或降低更新率

备选方案：

- `33` 柱 + `6.25kHz`
- 优点：频点更少，计算更轻
- 风险：端点不是整 `5kHz` 栅格，人工观察不如 `41/5kHz` 直观

## 3. 算法优先级

### 3.1 主方案

优先：`Goertzel / 定点频点能量`

- 每次直接计算目标频点集合：
  - `-100kHz ~ +100kHz`
  - 步进 `5kHz`
  - 共 `41` 点
- 输入：锁定后的复数基带 `I/Q`
- 输出：每个频点的能量或幅值
- 特点：
  - 不需要全频 FFT
  - 计算目标明确
  - 更适合“只显示固定频带摘要”的任务
  - 容易做成独立任务

### 3.2 备选方案

若 CMSIS FFT 已稳定：`512 点 CFFT`

- 先做 `512` 点复数 FFT
- 再从 FFT 结果中截取 `-100kHz ~ +100kHz` 范围映射到 `41` 柱
- 优点：
  - 后续可扩展成更完整频谱
  - 频点插值和峰值跟踪更方便
- 风险：
  - 当前工程接入和验证成本更高
  - 若 UI 刷新频率继续提高，更要注意 CPU 负载

## 6. Goertzel 频点集合

若采用 `41 / 5kHz`：

- `-100kHz`
- `-95kHz`
- `-90kHz`
- ...
- `-5kHz`
- `0Hz`
- `+5kHz`
- ...
- `+95kHz`
- `+100kHz`

复数基带下建议：

- 直接用复数形式的离散频点投影
- 对每个目标频点 `f_k` 计算：
  - `sum = Σ (I[n] + jQ[n]) * exp(-j 2π f_k n / Fs)`
  - `mag2 = re^2 + im^2`
- 从工程实现角度看，这更接近“定频点 DFT”，但可按 Goertzel/定点频点能量思路组织

## 7. 更新节奏建议

- 目标显示刷新：约 `10~15 Hz`
