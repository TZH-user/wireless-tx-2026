## 3.2 `ASK`

### 结果

#### 现象 B：`0.5 Vpp` 低电平 ASK 明显更像 AM

- `04_ASK_40M_a0p50_r10k`
  - `env≈787.2`
  - `edge≈40.6`

#### 现象 C：`5 kHz` ASK 边沿不够强

- `06_ASK_40M_a0p75_r5k`
  - `edge≈30.6`
  - `freq≈102.0`

当前 `edge >= 40` 直接把它挡在 `ASK` 外。

### 结论

当前 `ASK env + edge + freq` 方案失败。

失败原因分两层：

#### 第一层：必须先排除运行版本不一致

若板上根本不是当前源码，当前结论要先回到“版本一致性核验”。

#### 第二层：即便版本一致，当前 ASK 方案也不适合覆盖整个测试矩阵

原因：

- 对 `5 kHz`，`edge` 阈值偏高
- 对 `0.5 Vpp` 低电平 ASK，`freq_activity` 特征退化，已接近 AM
- 说明 `ASK` 不能继续只靠 `env + edge + freq`

### `ASK` 的后续可选方案

#### 方案 A：继续微调当前 `ASK` 最小改动方案

可试：

- 降 `APP_MODDET_ASK_MIN_EDGE_PM`
- 放宽 `APP_MODDET_ASK_MIN_FREQ_PM`

不推荐作为主方案。

原因：

- 一旦放宽过多，容易把 `AM` 吸进来
- 对 `0.5 Vpp` 这类点帮助有限

#### 方案 B：切换到 `ASK` 特征替换方案

建议新增：

- `env_low_ratio`
- `env_high_ratio`
- `env_hist_peak_count`
- `edge_burst_density`

推荐方向：

- 用“包络双态占比/双峰性”替代“env_level_count”
- `ASK` 优先按包络二态特征识别

这是推荐主方案。

## 3.3 `PSK`

### 结果

`PSK` 只在 `20 kHz` 条件下出现少量 `PSK` 命中，其余仍主要判成 `FM`。

具体表现：

- `10_PSK_40M_p180_r10k` -> 全部 `FM`
- `11_PSK_40M_p180_r5k` -> 全部 `FM`
- `12_PSK_40M_p180_r20k` -> `FM, PSK` 混合，只有部分块进 `PSK`

### 关键现象

#### 现象 A：`10 kHz` PSK 的符号偏置方向和规则相反

- `10_PSK_40M_p180_r10k`
  - `pos≈7`
  - `neg≈92`
  - `psk≈15.1`
  - `hist=1`
  - `freq≈101.2`

当前源码要求：

- `positive_freq_percent >= 80`
- `negative_freq_percent <= 20`

这会把整组 `10 kHz PSK` 全部过滤掉。

#### 现象 B：`5 kHz` 与 `20 kHz` 的 `hist` 有时为 `2`

- `11_PSK_40M_p180_r5k`：`hist=1,2`
- `12_PSK_40M_p180_r20k`：`hist=1,2`

当前源码要求 `hist == 1`，会丢掉一部分其实更像 PSK 的块。

#### 现象 C：`20 kHz` 已开始有部分块进入 `PSK`

- `12_PSK_40M_p180_r20k`
  - `psk≈30.4`
  - `freq≈111.1`
  - `env≈138.9`
  - `pos≈87.2`
  - `neg≈11.8`

说明当前路线不是完全错误，但约束写死了方向且过窄。

### 结论

当前 `PSK` 简化联合判据失败的主因不是 `psk_jump_pm` 太低，而是：

1. 把主频偏置方向写死为“正侧”
2. 把 `hist` 限死为 `1`
3. 没有加入足以和 `CW` 隔离的低频活动约束逻辑设计说明

### `PSK` 的后续可选方案

#### 方案 A：继续沿最小改动路线修正

建议改为：

- `max(pos, neg) >= 85`
- `min(pos, neg) <= 15`
- `freq >= 80`
- `psk >= 10` 或 `12`
- `env < 200`
- `hist in {1,2}`

说明：

- `max(pos,neg)` 取代“必须正频占优”
- `freq >= 80` 用来把 `CW` 挡掉
- `hist` 放宽到 `1 或 2`

这是推荐的短期主方案。

#### 方案 B：继续下调 `PSK` 阈值但不改结构

不推荐。

原因：

- 仅降门限无法解决 `10 kHz` 那种符号方向反转问题

#### 方案 C：块级相位跳变簇检测

长期推荐。

建议流程：

1. 相位估计
2. 相位差展开
3. 检测接近 `180°` 的跳变簇
4. 做块级统计而不是单采样点 `dot < 0`
