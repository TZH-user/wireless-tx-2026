## 5. 扩展矩阵阶段划分

### 5.1 阶段 A：频点扩展

目的：补齐 35MHz 和 45MHz，验证频点泛化。

频点：

```text
35MHz / 45MHz
```

每个频点测试：

```text
CW
AM  10kHz 50%
ASK 10kbps low=0VPP
FM  10kHz dev=75kHz
FSK 10kbps hop=+20kHz
PSK 10kbps 180deg
```

验收：

- `stable` 多数判决目标模式命中率 >= 80%。
- 每个 case 有效 `ui` 行不少于 10。
- 参数估计不得数量级错误。

### 5.2 阶段 B：幅度扩展

目的：验证输入幅度变化对分类和参数估计的影响。

建议固定频点：

```text
40MHz
```

幅度：

```text
0.75VPP / 1.0VPP / 1.5VPP / 2.0VPP
```

每个幅度测试：

```text
CW
AM  10kHz 50%
ASK 10kbps low=0VPP
FM  10kHz dev=75kHz
FSK 10kbps hop=+20kHz
PSK 10kbps 180deg
```

验收：

- 分类不能只在 1.5VPP 成立。
- AM/ASK depth 应随幅度变化保持合理趋势，不要求绝对精确。
- 低幅度若失败，必须区分是硬件 SNR 不足、扫频锁定问题，还是算法阈值问题。

### 5.3 阶段 C：速率扩展

目的：判断参数估计泛化，尤其是 FSK `rate` 是否需要 Goertzel/自相关/小 FFT。

建议固定：

```text
40MHz / 1.5VPP
```

调制速率：

```text
1k / 5k / 10k / 20k
```

测试模式：

```text
AM
ASK
FM
FSK
PSK
```

调制配置建议：

- AM：depth 50%。
- ASK：low=0VPP。
- FM：dev=75kHz。
- FSK：hop=+20kHz。
- PSK：180deg。

验收：

- `stable` 多数判决仍应目标模式命中。
- `rate_avg` 应随设定速率单调上升。
- 如果 `rate_avg` 对速率不敏感或严重反向，判定当前时域估计不适合该模式。
- 特别关注 FSK：若 FSK rate 在 1k/5k/10k/20k 下不能形成单调趋势，下一轮才建议 Goertzel/自相关。

## 7. 决策规则

### 7.1 可以直接放行的情况

如果阶段 A/B/C 全部满足：

- stable 分类通过率高。
- 参数估计无数量级错误。
- rate 对速率有基本单调趋势。

则不改算法，输出“扩展矩阵通过”。

### 7.2 只需 UI 标注的情况

如果 stable 分类通过，但某个参数精度不足：

- 不要马上改主分类器。
- 报告中标注该参数仅为估计值。
- 给出是否需要 Goertzel/自相关的证据。

### 7.3 需要算法修正的情况

只有满足以下条件，才允许提出小范围算法修正：

- 链路正常。
- 多个 case 出现同类稳定失败。
- 失败不是单一边界点。
- 能从日志字段中解释失败原因。

算法修正必须：

- 先备份。
- 更新 `fw_id`。
- 修改少量变量。
- 复测受影响矩阵。
- 输出修正前后对比。

### 7.4 Goertzel / FFT 决策

本轮不允许直接接完整 FFT 主链路。

如果需要频域辅助，优先建议：

1. Goertzel 检测指定速率附近能量。
2. 自相关估计符号周期。
3. 小窗口 RFFT 只用于参数估计，不用于替代 stable 分类主链路。

只有当阶段 C 证明时域 rate 估计在多速率下不可用，才建议下一轮实现 Goertzel/自相关。
