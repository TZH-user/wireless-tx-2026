## 修改原因

- tune1 在 30/50 MHz 端点：ASK 低电平 0 被判为 AM；PSK 在 30/50 MHz 被判为 CW；40 MHz PSK 有 FM 摆动。
- 端点 PSK 的瞬时频率活动可能很低，但相位翻转和包络边沿仍明显；端点 ASK 的频率活动不稳定，但包络变化和包络边沿明显。

## 修改内容

- `APP_MODDET_AM_ENV_PM_THRESHOLD` 从 350 提高到 450，减少 CW 偶发 AM。
- 新增 ASK 强包络分支：`env >= 850` 且 `edge >= 35` 可判 ASK，不再强制依赖 `freq >= 80`。
- 新增 PSK 边沿分支：单符号偏置、相位翻转高、包络变化低、`freq <= 130`，且满足 `freq >= 50` 或 `edge >= 40`。
- 放宽 PSK 直方图峰数到 `hist <= 2`，覆盖 40 MHz PSK 的 hist 摆动。

## 验证结果

- 30/40/50 MHz 共 18 个用例中 17 个多数判决通过。
- 失败点：`PSK_50M_10k_180` 多数判为 FM。日志显示其仍有单符号偏置和相位翻转，但 `freq_activity` 约 198-203，超过 tune2 的 PSK 上限 130。
- 结论：tune2 方向正确，但 PSK 频率上限过紧，进入 tune3。
