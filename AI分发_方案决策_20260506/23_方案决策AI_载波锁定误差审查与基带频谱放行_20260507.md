## 6. 策略采纳情况

采纳：

- 条件半步修正策略。
- 短日志拆分：`sigdet_final` + `sigdet_edge`。
- 预留 `raw_estimate_hz / demod_lo_hz / correction_hz / coarse_estimate_hz` 状态字段。

不采纳：

- 纯谷点策略。本轮离线比较显示谷点误差约 `1.1~1.25MHz`，不可用。
- 全局无修正策略。对部分频点仍存在 `+10~25kHz` 偏差。
- 立即锁定后微调。本轮 30/35/40/45/50MHz 不需要，且会增加复杂度。

暂不执行：

- FFT/Goertzel 残余差频估计。当前不作为载波锁定主链路改动。

## 7. 基带频谱显示功能放行条件

允许引入基带频谱显示，但必须遵守：

1. 只在 `APP_SIGDET_STAGE_VPP_LOCKED && locked && carrier_present` 后计算。
2. 不改变 ADC DMA、DDS 设置、扫频状态机和调制识别分类顺序。
3. 初版只作为屏幕显示/调试观测，不作为分类主判据。
4. 输入数据使用现有 I/Q block，优先低负载实现，避免影响 ADC 任务实时性。
5. FFT/频谱计算建议放在独立模块或低频 UI 更新路径，不要在 ADC 高频路径里做大计算。
6. 显示频谱时必须标注当前 `LO/demod_lo_hz` 与 `Carrier/estimated_carrier_hz`，避免把基带残余频率误读为 RF 绝对频率。
7. 仍执行 RF 输入上限：`<=1.5VPP`。

## 8. 推荐实现路线

建议让改代码 AI 执行，顺序如下：

1. 新增基带频谱模块，例如：
   `Core/App/Signal/app_baseband_spectrum.c/.h`
2. 输入：锁定后的 I/Q block。
3. 初版输出：主峰频率、主峰幅度、噪声底估计、频谱有效标志。
4. UI 只显示摘要，不先画复杂全频谱曲线：
   - `Baseband Peak: xx Hz`
   - `Peak Mag: xx`
   - `Noise: xx`
   - `LO: xx MHz`
5. 如果要画图，优先小点数 bins，例如 32 或 64 个柱状点，避免 LVGL 绘制负载过高。
6. 频谱结果先不接入 AM/FM/FSK/PSK 判决，只作为观测和后续算法证据。

## 9. 风险与限制

- 本轮载波锁定只验证 CW 整点频率，不覆盖任意小数频点或漂移信号。
- 当前细扫步进仍为 `50kHz`；非网格频率的最终显示和 LO 仍可能有量化误差。
- 基带频谱如果直接对含 DC 偏置的 I/Q 做 FFT，需要先去均值或高通，否则 DC 峰会压制有用峰。
- ADC 当前仍有 `adc_range` 等测试日志，后续接入频谱前建议确认串口负载是否可接受。
