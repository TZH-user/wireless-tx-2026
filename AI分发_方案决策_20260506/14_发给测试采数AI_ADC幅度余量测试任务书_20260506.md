# 发给测试采数 AI：ADC 幅度余量与失真边界测试任务书（2026-05-06）

## 0. 任务背景

用户发现：当 RF 输入达到 `2VPP` 时，LTC5584 的 I/Q 输出可能已经超过 ADC 可接受幅度，导致 ADC 数据削顶或失真。

本轮目标不是调制识别算法，而是确定：

```text
在当前 RF -> LTC5584 -> LPF/偏置 -> ADC 链路下，RF 输入多少 VPP 以内 I/Q ADC 数据不会明显失真。
```

测试结果将用于后续规定安全输入幅度，以及解释为什么部分调制参数在高幅度下反而异常。

## 4. 必须增加或确认的日志字段

现有 `sig` 日志里有：

```text
v=<current_vpp_raw>,p=<peak_vpp_raw>,n=<valley_vpp_raw>
```

但这不足以判断 ADC 是否削顶。建议增加专用日志：

```text
adc_range,i_min=<raw>,i_max=<raw>,q_min=<raw>,q_max=<raw>,i_vpp=<raw>,q_vpp=<raw>,i_clip_low=<n>,i_clip_high=<n>,q_clip_low=<n>,q_clip_high=<n>,i_near_low=<n>,i_near_high=<n>,q_near_low=<n>,q_near_high=<n>,samples=<n>
```

建议判定阈值：

- ADC 当前为 14bit，但 DMA 数据类型为 `uint16_t`，请以实际采样数据范围为准。
- 若数据左对齐或扩展到 16bit，满量程附近可能接近 `0 / 65535`。
- 先从日志实际 min/max 判断有效满量程形态。
- `near rail` 可暂定为距上下轨 `1%FS` 内。
- `clip` 可暂定为连续或大量样本接近上下轨，例如 `raw <= low_threshold` 或 `raw >= high_threshold`。

如果不确定 ADC 数据是否左对齐：

- 先采 `0.2VPP`、`1.0VPP`、`2.0VPP` 三点。
- 根据 min/max 分布判断数据实际上限。
- 在报告中说明判定依据。

## 7. 判定标准

### 7.1 明显安全

满足以下条件可判为安全：

- I/Q 均无 clip count。
- near rail count 很低，例如 `< 0.1% samples`。
- min/max 距上下轨仍有明显余量。
- I/Q vpp 随 RF VPP 增加大致单调。

### 7.2 接近边界

满足以下任一条件判为接近边界：

- near rail count 明显增加。
- min/max 距上下轨小于约 `2%FS`。
- I/Q vpp 增长开始变慢。
- 波形峰值统计出现压扁迹象。

### 7.3 失真/削顶

满足以下任一条件判为失真：

- clip count 非零且重复出现。
- near rail count 显著，例如 `> 1% samples`。
- RF VPP 增加但 I/Q vpp 不再线性增加。
- I/Q min/max 长时间贴近上下轨。
